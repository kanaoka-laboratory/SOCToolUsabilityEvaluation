# **Overview**

This directory contains documentation related to the usability evaluation method used in our study on SOC tools. The methodological background, rationale, and full analysis are described in the accompanying research paper (not yet publicly available).

The materials here supplement that work and provide the documents necessary to understand and reproduce the evaluation procedure.

## **Included Documents**

* **evaluationcriteria.md**
  Contains detailed descriptions of the eleven usability evaluation criteria used during the heuristic walkthrough.

Additional supplemental materials or methodological notes may be added as the project develops.
